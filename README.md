Project Overview
Understanding how different regions implement Natural Capital Accounting for sustainable development

1
Research Question
How do implementation frameworks, institutional capacities, and policy applications of NCA differ between EU SEEA and South Asian approaches?

2
Key Regions
EU regulatory frameworks compared with context-specific approaches in India, Bhutan, and Sri Lanka.

3
Integration Focus
Emphasis on sustainable finance mechanisms and policy applications for decision-making.

Research Components
Implementation Status
Mapping NCA development stages across regions:

EU: Full to advanced implementation with systematic policy integration
India: Pilot phase with forest, water, and land accounts
Bhutan: GNH integration with constitutional mandate
Sri Lanka: Early-stage development with experimental accounts
Data Collection
Primary Sources

National statistical office reports, ministry documents

Secondary Sources

UN SEEA database, World Bank WAVES reports, EU Open Data Portal

Methods

Policy document analysis, meta-analysis of NCA indicators, stakeholder interviews

Methodology & Phases
Phase 1: Baseline Assessment
Literature review, policy document collection, stakeholder mapping

Phase 2: Data Collection
Comparative coding framework, NCA account data collection, mini case studies

Phase 3: Dashboard Development
Data pipeline setup, visualization modules, comparative analysis integration

Phase 4: Validation
Expert review, stakeholder feedback, final documentation

Comparative Variables
Institutionalization Level

Legal mandate to operational implementation

Account Coverage

Physical, monetary, and ecosystem accounts

Policy Integration

Informational to instrumental use

Data Infrastructure

Traditional statistics to geospatial integration
